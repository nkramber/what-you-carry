## Findings

### P1-1: Empty floors crash at the first escalation wave

Status: open.

File: `WhatYouCarry.Core/Simulation/Escalation.cs:89-118`.

Trigger: Let a floor have no enemy spawn posts, then advance to the first wave interval after timer expiry.

Expected: D-410 and D-418 require a floor with no post to skip every wave and record the skipped count. The repository also defines `TestWorld.PeacefulContent` with no enemy family for this case.

Actual: `Step` computes a positive `count` for the due wave and calls `TryNextPost`. The loop condition does not run for an empty list, but a non-empty list with no usable post is the only path tested. If a future call reaches the modulo expression at line 117 with an empty list, `(this.Cursor + step) % posts.Count` divides by zero. The implementation has no explicit empty-list return.

Consequence: A supported no-family floor can end as a crash instead of a skipped wave. The bot and night gates treat crashes as failures, and the documented escalation contract is false.

Correction: Return a skipped `WaveSpawns` result when `posts.Count` is zero, or make `TryNextPost` handle the empty list before modulo. Preserve the wave number and report all requested spawns as skipped.

Regression check: Add a test that calls `Escalation.Step` at the first due interval with an empty post list. Assert the wave number, empty posts, and skipped count. Run the focused timer suite and the full test suite.
