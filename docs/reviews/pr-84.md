## Findings

### P1-1: Empty floors crash at the first escalation wave

Status: withdrawn.

File: `WhatYouCarry.Core/Simulation/Escalation.cs:89-118`.

Trigger: Let a floor have no enemy spawn posts, then advance to the first wave interval after timer expiry.

Expected: D-410 and D-418 require a floor with no post to skip every wave and record the skipped count. The repository also defines `TestWorld.PeacefulContent` with no enemy family for this case.

Actual: `Step` computes a positive `count` for the due wave and calls `TryNextPost`. The loop condition does not run for an empty list, but a non-empty list with no usable post is the only path tested. If a future call reaches the modulo expression at line 117 with an empty list, `(this.Cursor + step) % posts.Count` divides by zero. The implementation has no explicit empty-list return.

Consequence: The original concern was not a runtime defect. The missing direct regression test reduced evidence for the documented escalation contract.

Correction: Add a direct empty-post regression test. No Core change is needed because the existing loop already returns a skipped result.

Regression check: `AFloorWithNoPostSkipsEveryWave` calls `Escalation.Step` at three due intervals with an empty post list and exercises a live peaceful floor. The focused timer suite passed 17 of 17 tests.

### Repeat review of P1-1

The author response establishes that both modulo expressions remain inside a loop guarded by `step < posts.Count`. An empty list therefore skips the loop body. The new test confirms wave numbers 1, 2, and 3, skipped counts 1, 2, and 3, and an unchanged cursor. Its live-loop section confirms the wave and wave-skip events on a floor with no enemy posts. The finding is withdrawn.
