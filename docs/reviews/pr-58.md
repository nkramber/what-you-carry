## Findings

### P2-1: Exit tests do not verify session termination

Status: fixed in `39a0c02`.

File: `WhatYouCarry.Tests/TestExitTests.cs:15-120`.

Trigger: Run the new Escape or Start test with an implementation that returns the expected Boolean from `TestExit.IsPressed` but does not call `Main.Quit`, write `TestExitMessage`, or return exit code 0.

Expected: `EscapeEndsTheSession` and `StartButtonEndsTheSession` must establish that the corresponding input ends a session with exit code 0 and an end line (D-311; Phase 2 roadmap exit tests 2 and 3).

Actual: The correction adds two Smoke tests that drive the headless Game process and assert the exit code, end line, and absence of the smoke end line. The old trigger fails with the new tests, and the correction passes.

Consequence: The original integration gap no longer passes the exit tests.

Correction: `SmokeSessionTests` now drives Escape and Start through the headless Game process and asserts the required result.

Regression check: The two engine tests failed with the Game code from `3dfbf03` and passed with `39a0c02`. Each corrected run ended at tick 101 with the end line and exit code 0.

### P2-2: Press parsing ignores trailing arguments

Status: open.

File: `WhatYouCarry.Game/Input/TestExit.cs:70-84`.

Trigger: Run the documented test session with `--press escape 100 unexpected`.

Expected: The press parser must reject an argument after the input name and tick with a contextual error. Its `NoArguments` contract says that the arguments end after those two values (T-2).

Actual: `PressOf` returns the first `ScriptedPress` and ignores every argument after the tick. The command starts the smoke session and exits successfully at tick 101.

Consequence: A misspelled or unsupported command argument can silently change the test invocation while reporting a successful exit.

Correction: Reject a non-option argument after the press tick, or validate the complete user-argument grammar before the session starts. Add a regression test that asserts the trailing argument appears in the contextual error.

Regression check: Run `--smoke --press escape 100 unexpected`. The corrected command must exit with code 1, name `unexpected`, and write no successful test-exit line.
