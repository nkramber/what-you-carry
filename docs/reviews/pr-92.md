## Findings

### P2-1: Layout bounds can wrap and accept an invalid canvas

Status: open.

File: `WhatYouCarry.Assets/TextureLayout.cs:271-272`.

Trigger: A layout gives a canvas `x = 2147483647`, `width = 1`, and valid positive values for the other fields.

Expected: Reject the canvas because it lies outside the 512-pixel atlas (G-7, T-2, D-506).

Actual: The `int` sum of `x` and `width` wraps to a negative value. The bounds check accepts the rectangle, and the game uses its invalid atlas origin.

Consequence: A malformed layout can silently render a canvas from outside the atlas instead of reporting the bad field.

Correction: Check the rectangle end with wider arithmetic, or compare each size with the remaining atlas extent.

Regression check: Add layout parse cases with overflowing `x + width` and `y + height`. Each must throw `ContextException` with the layout path and `at` field.
