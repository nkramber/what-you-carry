## Findings

### P2-1: Atan2 loses negative zero on the negative x-axis

Status: open.

File: `WhatYouCarry.Core/Determinism/DetMath.cs:110-137`.

Trigger: call `DetMath.Atan2(-0.0f, -1.0f)`.

Expected: D-161 requires an error of at most 1e-6 against the double reference.

Actual: `y < 0.0f` is false for negative zero. The method returns positive pi, while `Math.Atan2` returns negative pi.

Consequence: the error is two pi for a finite, valid vector. The raw result bits also differ from the reference.

Correction: preserve the sign bit of zero when the method selects the result sign.

Regression check: add the negative-zero axis case to `Atan2Accuracy`, and require the negative-pi result.

### P2-2: A default StateHash silently uses the wrong FNV offset

Status: open.

File: `WhatYouCarry.Core/Determinism/StateHash.cs:21-49`.

Trigger: initialize `StateHash hash = default`, then add a field.

Expected: D-160 requires FNV-1a 64, which starts from its offset basis. T-2 prohibits a silent absent value.

Actual: the public struct starts with zero. It accepts fields and produces a non-FNV hash with no error.

Consequence: a normal default initialization can produce a stable but invalid simulation identity.

Correction: make default construction valid, or reject an uninitialized hash before it accepts or returns data.

Regression check: compare a default hash with `StateHash.Start()` after the same field, or assert a contextual error.

### P2-3: The lint check does not detect reflection through System.Type

Status: open.

File: `WhatYouCarry.Tools/DetLint/BannedSymbols.cs:31-64`.

Trigger: scan Core code that calls `typeof(string).GetMethods()`.

Expected: G-2 prohibits reflection in Core, and the new lint check enforces the Core determinism rules.

Actual: the scan reports no finding because the code does not spell `System.Reflection`.

Consequence: the required lint check can pass Core code that directly uses reflection.

Correction: detect reflection APIs that do not name the namespace. Keep legitimate type operations available where G-2 permits them.

Regression check: scan the trigger and require an `L-REFLECTION` finding.

### P2-4: Any file named DetMath.cs receives the MathF exemption

Status: open.

File: `WhatYouCarry.Tools/DetLint/CoreSourceScan.cs:67-72`.

Trigger: scan `WhatYouCarry.Core/Other/DetMath.cs` with a call to `MathF.Sqrt`.

Expected: only `WhatYouCarry.Core/Determinism/DetMath.cs` can call the allowed `MathF` members under G-2.

Actual: the scan compares only the file name and reports no finding.

Consequence: a second file can bypass the `MathF` boundary while the required check stays green.

Correction: compare the normalized Core-relative path with the one canonical DetMath path.

Regression check: scan the trigger path and require an `L-MATHF` finding.
