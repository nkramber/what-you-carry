## Findings

### P2-1: Atan2 loses negative zero on the negative x-axis

Status: fixed in `1bc665b`.

File: `WhatYouCarry.Core/Determinism/DetMath.cs:110-137`.

Trigger: call `DetMath.Atan2(-0.0f, -1.0f)`.

Expected: D-161 requires an error of at most 1e-6 against the double reference.

Actual: `y < 0.0f` is false for negative zero. The method returns positive pi, while `Math.Atan2` returns negative pi.

Consequence: the error is two pi for a finite, valid vector. The raw result bits also differ from the reference.

Correction: preserve the sign bit of zero when the method selects the result sign.

Regression check: add the negative-zero axis case to `Atan2Accuracy`, and require the negative-pi result.
