## Findings

### P2-1: Reject a short PNG header before reading its fields

Status: open.

Open at: `4edcd2c488789729eee5c5a3f409cce80a756fba`.

File: `WhatYouCarry.Tools/TextureTrace/ScreenshotPng.cs:75-79`.

Trigger: A malformed screenshot has an `IHDR` chunk shorter than 13 bytes. The chunk loop checks that the declared chunk fits, but the header branch reads fixed offsets without checking its length.

Expected: Reject the screenshot with a `ContextException` that names the path and the invalid header. T-2 requires context for every error, and PR-90 exit test 4 covers screenshot reader errors.

Actual: A short but complete `IHDR` chunk reaches `ReadInt` and array reads at offsets beyond the file. Those reads throw an index exception. `TextureTraceCommand.Run` catches only `ContextException`, so the malformed input escapes the command's error path.

Consequence: A damaged or truncated screenshot can terminate `texture-trace` with an unhandled exception instead of the promised input error.

Correction: Check that an `IHDR` chunk has exactly 13 data bytes before reading its fields, and report a contextual error when it does not.

Regression check: Add a short-`IHDR` case to `TextureTraceTests` and assert a contextual `ContextException`. Run `dotnet test WhatYouCarry.slnx --filter FullyQualifiedName~TextureTraceTests` and confirm the test passes.
