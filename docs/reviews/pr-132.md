### P2-1: Security updates do not use cross-directory grouping

Status: fixed in `6da30feac32c67e8ab05962833b2ea87bbf4340d`.

Open at: `33f81fe3f011072f236bbdd7f94246674fa08e48`.

File: `.github/dependabot.yml:19-22`.

Trigger: Dependabot raises a security update for an action used in `/` and in `/.github/actions/*`.

Expected: D-774 groups version updates for an action across directories. D-657 enables security updates. D-776 adds a security update group across those directories.

Actual: At `33f81fe`, the `each-action` group had no `applies-to` key, so it applied to version updates only. The correction adds a `security` group with `applies-to: security-updates` and the pattern `"*"`. GitHub documents that a group without `applies-to` defaults to version updates, and that security groups cover directories in a `directories` configuration.

Consequence: Before the correction, one security update could leave the action on two pins. The new security group covers that case. It can put multiple actions with advisories in the same PR, as D-776 specified for this round.

Correction: `.github/dependabot.yml` adds the security group. D-774 states that its existing group covers version updates only. D-776 records the security update policy.
