### P2-4: A parenthesized span can terminate at a delimiter inside a quoted span

- Commit: `d55666d`
- Location: `WhatYouCarry.Tools/SteCheck/SentenceText.cs:137-143`
- Trigger: A parenthesized span contains a quoted `)` character, such as `Read ("a) b") now.`
- Expected: Rules 8.5 and 8.6 make text in parentheses and double quotes opaque. The complete parenthesized span must count as one word.
- Actual: `Mask` masks quotes before it masks parentheses, but `MaskChar` preserves parentheses. `MaskSpans` then treats the `)` inside the quote as the close for the outer parenthesis. The remaining text becomes a separate token, so the checker can report the wrong word count or inspect quoted text.
- Evidence: `Mask` calls `MaskSpans` for quotes on line 141 and parentheses on line 143. `MaskChar` leaves `(` and `)` unchanged on lines 199-210. `FindSpanEnd` therefore cannot distinguish a parenthesis inside a quoted span from a real close delimiter. No test covers a quote or code span that contains a parenthesis used as a delimiter.
- Correction: Preserve the opacity of already masked spans while the later masking pass scans delimiters. Add regression tests for parentheses that contain quoted `)` and code `` `)` `` text, and assert one opaque word with no grammar findings.
