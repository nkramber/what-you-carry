## Findings

### P2-1: Weapon asset paths accept invalid locations and file types

Status: open.

File: `WhatYouCarry.Core/Content/WeaponDefinition.cs:176-184`.

Trigger: Give `model` the value `models/../floors/a.json`, or give `animation` the value `models/player.bbmodel`.

Expected: The weapon validator accepts a model path only under `models/` with the model extension and accepts an animation path only under `models/` with the animation extension. It rejects dot segments. This follows D-298, D-302, and D-330.

Actual: `AssetPath` checks only that the value starts with `models/`. Both invalid values pass `WeaponDefinition.FromMembers`.

Consequence: Invalid content passes Core validation. Game later combines the path with the content directory and can read a sibling content file or parse the wrong asset type. The content error then occurs at boot instead of at the weapon file that caused it.

Correction: Validate the model and animation fields with separate path checks. Reject rooted paths, dot segments, incorrect extensions, and paths outside the model directory. Add regression tests for traversal and for each swapped extension.

Regression check: `ContentTests` must reject both triggers through `WeaponDefinition.FromMembers`, while valid model and animation paths must continue to load.
