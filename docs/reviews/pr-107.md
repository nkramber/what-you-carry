## Findings

### P2-1: Blend accepts a zero part count

Status: open.

Open at: `e4a097ed2d31700ddbf7199163331e59fb0193e8`.

File: `WhatYouCarry.Tools/TextureGen/LinearLight.cs:74-82`.

Trigger: A caller invokes `LinearLight.Blend(0, 255, 0, 0)`. The weight check accepts zero because the weight equals the part count.

Expected: The blend needs a positive part count. Invalid input must fail with a contextual argument error under T-2.

Actual: The method divides by `parts` and throws `DivideByZeroException`.

Consequence: A caller that supplies a zero denominator gets an unrelated arithmetic failure from a new public API.

Correction: Reject `parts <= 0` with `ArgumentOutOfRangeException` before checking the weight or dividing.

Regression check: Add a test that passes zero parts and expects `ArgumentOutOfRangeException`; retain the existing endpoint and out-of-range weight checks.
