## Findings

### P2-1: The analysis command writes outside the sound directory

Status: fixed in `996b3c343cbd528b419ae72177e7bb7908453606`.

File: `WhatYouCarry.Tools/AudioSynth/AudioAnalyzeCommand.cs:83-93`.

Trigger: Run `audio-analyze --root <checkout> --sound ../../../pwn` when the corresponding reference file exists.

Expected: The command must accept one sound name and keep its output under `content/audio/sfx/` (T-2 and the CLI file-path boundary).

Actual: The command joins `sound` directly into both paths. The isolated reproduction exited 0 and wrote `pwn.json` at the checkout root, outside `content/audio/sfx/`.

Consequence: A mistyped or untrusted sound name can overwrite a JSON file outside the intended directory.

Correction: `AudioAnalyzeCommand.IsOneName` rejects empty names, dot segments, path separators, colons, and platform-invalid file-name characters before the command builds either path.

Regression check: `TheAnalysisTakesOneFileName` runs the command for five invalid names, including `../../../pwn`. It asserts exit code 2 and that neither the outside path nor the sound directory gains a file. The full suite passed all 1301 tests on the fixed head.

### P2-2: An overflowing WAV chunk length escapes validation

Status: fixed in `996b3c343cbd528b419ae72177e7bb7908453606`.

File: `WhatYouCarry.Tools/AudioSynth/WavReader.cs:39-58`.

Trigger: Read a short RIFF file whose chunk length is `2147483640`.

Expected: Reject the chunk with a contextual error that names the file and chunk (D-461, T-2, and D-113).

Actual: `body + length` overflows, the next offset becomes negative, and `Tag` throws an unhandled `ArgumentOutOfRangeException`. The isolated `audio-analyze` reproduction printed an exception stack trace instead of a file error.

Consequence: A malformed reference crashes the tool without the required file and field context.

Correction: `WavReader` compares the chunk length with `bytes.Length - body` before it adds the length to the offset, so an overflowing sum cannot pass the bounds check.

Regression check: `AWavChunkPastTheEndFails` checks lengths 2147483640, `int.MaxValue`, and 40. Each must produce a `ContextException` naming the file, chunk, and bounds error. The full suite passed all 1301 tests on the fixed head.
